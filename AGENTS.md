# Темари — вход для разработки

Это личный проект в Home. Читать `STATE.md`, `AGENTS.project.md` и правила родительского `Home/CLAUDE.md`.

Модель и её допущения: `spec/embroidery-model.md`; ремесленные основания: `spec/craft-sources.md`; проверочные контракты: `src/components/temari/rules.md`. Источники важнее прежней реализации, но математические и ремесленные утверждения требуют собственной проверки.

При изменении рецепта, геометрии, поддержки разметки или способа исполнения обновлять связанные документы и GitHub issues в том же этапе. Различать «спроектировано», «реализовано», «проверено численно», «проверено визуально» и человеческую приёмку. Указывать снимок кода для результатов; исторические выводы не выдавать за текущие.

Публичная документация редактируется только в `public/design.html`; короткий адрес задаёт `public/design/index.html`. После правки запускать `node scripts/sync-design.mjs --write`, затем `--check`. Проверять страницу в браузере, включая узкий экран и ссылки. Не править зеркала вручную. Pages workflow запускает `npm ci`, тесты, typecheck и `npm run build`, затем публикует свежий `dist/`. Входы: `index.html`/`src/pages.tsx` и `lab.html`/`src/lab.ts`; сборки не коммитить. Новая ветка сама по себе не обновляет живой сайт.

Пользователь разрешил коммитить и публиковать законченные проверенные изменения сразу. Отдельная приёмка мастером/пользователем от этого не считается пройденной.

Режим пользователя: Astra Ultra для обоснования модели/архитектуры и трудных математических вопросов, High для реализации. Сохранять решения в проекте; избегать повторных полных обзоров.
