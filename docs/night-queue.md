## Правила

- **Перед пушем:** `npm test`, `npm run typecheck`, `npm run build`, `npm run check:docs`.
  Красное не пушить. После пуша на следующей итерации — `gh run list --branch codex/temari-next`.
- **Коммит:** одна правка, заголовок `fix:`/`feat:`/`test:`/`docs:` + что и зачем; в теле — цифры
  до/после и чем проверено.
- **Нельзя:** подбирать константы ради зелёного счётчика или locate; ослаблять или удалять тесты;
  прятать пересечения под мари; менять ширину и шаг верхнего стежка; трогать `main`.
- **Две попытки на задачу.** Если критерий не выполнен — откатить рабочее дерево, записать в журнал
  «заблокировано: причина, что пробовал», перейти к следующей.
- **Кадры** — только скрытым браузером (ночь), по рядам в цвете, до/после.
- **Стоп:** очередь пуста; три блокировки подряд; недельный лимит ≥ 80%; 5-часовой ≥ 90% — ждать
  сброса; 08:00 по местному времени — итог в журнал и сообщение владелице.
