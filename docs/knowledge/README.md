# База знаний: темари (ремесло → модель → симулятор)

Обновлено: 24.09.2026. Это **исследовательский слой** проекта: отдельно от исполняемого кода (`src/`) и инженерных контрактов (`spec/`). Цель — объяснять вышивку человеку, показывать последовательность и питать симулятор **проверяемыми** утверждениями.

## Статусы утверждений

| Метка | Значение |
|--------|-----------|
| **источник** | Дословный или близкий пересказ первичного материала с URL и автором |
| **вывод** | Логическое следствие из источника и/или геометрии; область применимости указана |
| **гипотеза** | Рабочая модель до проверки |
| **численно** | Подтверждено тестами/расчётом в репозитории (указан снимок/модуль) |
| **визуально** | Сверено с кадром браузера или фото; не заменяет ремесло |
| **мастер** | Приёмка человеком-вышивальщиком; **не выдаётся агентом** |

Чтение источника или прохождение тестов **не равно** квалификации мастера.

## Базовый образец для разбора

**[GT14](https://www.temarikai.com/PatternsPages/Simple/GT14.html)** (Ginny T., 2011): Simple 8, **uwagake chidori kagari**, кику у полюса, две группы цветов A/B, парковка между группами, работа до экватора. Полный пошаговый trace — в [gt14-process-trace.md](gt14-process-trace.md).

npm run test:fast
