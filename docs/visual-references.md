## Как сравнивать с симулятором

1. Записывать конкретный экспонат, технику и материал, если они установлены. Для проверки
   острия кику выбирать источник с соответствующим стежком; для общего вида — отдельный критерий.
2. Различать опубликованный C/D и размер шара на экране. Сравнивать несколько похожих ракурсов,
   показывать шар целиком и деталь. Увеличение изображения не добавляет измерительной точности.
3. Проверять пропорции нитей к шару, плотность рядов, локальный рельеф, видимость пересечений
   и характер бликов. Не выводить универсальную толщину из одного фото неизвестной нити.
4. Снимок симулятора фиксировать по коммиту, параметрам материала, рядам и камере; для вышивки
   сохранять цвета рядов с легендой и обычный вид рядом по правилам проекта.
5. Расхождение сначала формулировать наблюдением, затем проверять рецепт и геометрию.
   Фото готового изделия не заменяет проверку процесса или ремесленную приёмку.
