# Расход нити: что найдено у мастеров

23.09.2026. Ограниченный поиск первичных записей на русском, английском и японском.
Это журнал оснований для [программы калибровки](craft-calibration-program.md), не набор
измеренных изделий. Состояние кода при сравнении: `1dd140b`.

**Результат:** найдены практические ориентиры намотки с размером мари. Сопоставимой серии
измерений расхода вышивки, где известны размер, материал, точный узор, ряды и область работы,
пока нет. Это результат ограниченного поиска, не утверждение об отсутствии таких записей.
Среднее не рассчитано; параметры модели по этим сведениям не менялись.

## Что можно рассчитать, а чего нельзя

1. **Геометрическую длину заданного пути.** Например, пять полных больших кругов разметки
   S8 на идеальной сфере C24 см дают 1,20 м, без закреплений и переходов. Это вывод из
   геометрии, не проверенный по мастеру расход всей разметки.
2. **Условную связь покрытия и расхода.** Площадь сферы `A = C²/π`. Для тонкой нити с
   эффективной шириной следа `w` и уложенной длиной `L` средняя кратность покрытия
   приближённо `n ≈ Lw/A = πLw/C²`. Все длины — в одинаковых единицах; ростом радиуса
   от слоёв пренебрегаем. Это площадь следов с учётом повторений, а не гарантия отсутствия
   просветов при случайной намотке. По одним C и L нельзя разделить ширину нити, число слоёв
   и характер перекрытий; высота сечения и сжимаемость тем более не определяются.
3. **Масштабировать только при явных условиях.** Геометрически подобный поверхностный
   путь при неизменном числе проходов даёт `L ∝ C`. При постоянных `w` и средней кратности
   покрытия из предыдущего соотношения получается `L ∝ C²`. Это разные задачи. Рецепт
   с фиксированными расстояниями в мм, добавлением рядов и концами не обязан следовать
   одному из этих законов целиком. Универсальное усреднение `L/C²` для разных узоров неверно.

### Сверка с нынешним кодом не является независимой калибровкой

`src/components/temari/measure.ts` использует назначенный `CRAFT_PACK = 2,5` для закупочного
количества швейной нити. На C24 вызов `wrapBom(24)` даёт 448 витков и 107,52 м геометрической
длины, а после множителя — 268,8 м (старый комментарий в коде про 449 витков устарел).
История `5a83655`, `public/design.html`, прямо связывает выбор ×2,5
с ориентиром TemariKai 300 yd (≈274 м). Повторное совпадение с ним — сверка с исходным
ориентиром настройки, не независимая валидация. Инструкция не устанавливает универсальный
коэффициент 2,5. Не подгонять этим сравнением ширину, число витков или расход вышивки.
Закупка и уложенная длина остаются разными полями.

Кроме того, нынешняя формула `wrapsToCover` без округления даёт
`N = C × overlap / (2w)`: это средняя кратность `π × overlap / 2 ≈ 1,76` при `overlap=1,12`,
ещё до закупочного множителя. Её нельзя называть точным однократным покрытием площади.

## Следующий поиск или измерение

Искать независимые работы с одним воспроизводимым рецептом (первый кандидат — GT14),
близким C и одной маркой/размером нити. На каждую работу сохранять:

- прямую ссылку, автора и дату; отличать оригинал, повтор и пересказ;
- исходное C или D и момент измерения (готовая мари либо сердцевина);
- материал и число сложений, узор/разметку, число рядов, полюсов и центров;
- компонент расхода и область: намотка, разметка, вышивка, концы, отходы;
- исходную величину/единицу, способ измерения, остаток и погрешность;
- статус: измерено, оценено автором, рекомендовано к подготовке или объём упаковки.

Неизвестное оставлять неизвестным. Длина отрезанных заготовок за вычетом остатков даёт
расход с отходами, а не обязательно длину уложенной нити. Массу переводить в метры только
по линейной плотности именно этой нити с описанным измерением. Несколько изделий одного
мастера не считать независимыми мастерами.

Сначала сравнивать прогноз и факт одной области по каждому образцу, затем группировать
сопоставимые образцы и показывать разброс. Три записи годятся для первого сопоставления,
но сами по себе не устанавливают надёжную среднюю норму. Отдельные работы оставить для
проверки после калибровки. Текущие оценки источников не импортированы в паспорт как измерения.
