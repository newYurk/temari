## Каталог крутых идей (главное)

| # | Идея | Суть | Статус |
|---|---|---|---|
| I1 | **Метраж по полной нити** | Считать поверхность + прокол + скрытое + start/finish **по каждому цвету / `WorkingThread`** | идея |
| I2 | **Прозрачный мари для проверки** | Вкл/выкл прозрачность → видно «внутри»; контроль, что метраж ничего не забыл | идея |
| I3 | **Две цифры расхода** | «По шитью» (сумма путей) и «к закупке» (× запас, пока оценка) | идея |
| I4 | **Лента шагов вышивки** | Выход: `A·круг1 → park → B·круг1 → resume A·…` — шить у стола | идея |
| I5 | **Полярная «ромашка»** | Вид с полюса: наборы A/B на лучах, номера кругов | идея |
| I6 | **Развёртка одного набора** | Кольцо верх–низ–верх… «где я сейчас» | идея |
| I7 | **Слои / луковица** | Ранние круги внутри; финиш 3-го цвета — внешнее кольцо на обоих наборах | идея |
| I8 | **Мини-кадры catch** | Один верх или низ крупно, как в Toolkit | идея |
| I9 | **MVP выхода** | Сразу достаточно: лента + ромашка + метраж (I4+I5+I1) | идея |
| I10 | **Подсветка всей физической нити** | Тап/наведение → светится всё от `start` до `finish`; park/resume = та же нить; после обреза новый моток = другая | идея |
| I11 | **Режим «только эта нить»** | Приглушить остальное; опц. сравнить две (A vs B) | идея |
| I12 | **Карточка нити** | Цвет, длина, круги, parked?, обрезана? | идея |
| I13 | **Перекрасить после факта** | Тот же путь, другой оттенок — без распуска; мечта мастера «надо было чуть другой цвет» | идея |
| I14 | **Заменить / удалить = распустить** | Не тихий пересчёт толщины: показать **какие слои снять** (как на живом мари), потом заменить/убрать | идея |
| I15 | **Запрет «весь белый одним кликом»** | Несколько физических мотков одного hue — не одна кнопка перекраса | идея |
| I16 | **Взгляд мастера на продукт** | Приложение = разметочный стол + лупа + журнал порядка; не замена пальцам; полезно, только если не врёт ремеслу | идея (рамка) |
| I17 | **«Где я»: лента ↔ шар** | Текущий шаг на ленте и тот же catch в 3D подсвечены вместе; вернулась к телефону — снова виден луч | идея |
| I18 | **Призрак следующего стежка** | Режим ученицы: полупрозрачно куда уложить и где прокол; без автошитья (*lay then stitch*) | идея |
| I19 | **Превью роспуска до подтверждения** | Перед удалить/заменить — призраком снять будущие слои и подписать «уйдёт ~X мм нити …» | идея |
| I20 | **Генеалогия нити** | Не только «что она прошла», а **что на ней лежит** — для распуска и клина | идея |
| I21 | **Сколько до экватора** | На 4+4: A и B поровну — ещё N кругов каждой (GT14 equal rounds) | идея |
| I22 | **Дневник у стола (одна страница)** | Экспорт: ромашка + лента + метраж по цветам — печать / чат ученице, без живого 3D | идея |
| I23 | **Ссылка «история одной нити»** | Открыли — шар уже с подсвеченным `WorkingThread` | идея |
| I24 | **Калибровка к паспорту** | Факт длины с живого мари рядом с «модель сказала Y» — корм для коэффициента запаса | идея |
| I25 | **Чеклист булавок до старта** | «Полюс + нижние метки стоят» → потом шить | идея |

## Развёртка идей

### I1–I3. Метраж и прозрачность

Полный путь модели можно суммировать по зонам и по нитям/цветам. Прозрачный мари — проверка глазом, что «внутри» учтено.

Две цифры человеку:
1. по шитью;
2. к закупке (= путь × запас; до калибровки — честно «оценка»).

Park длины не добавляет; finish / длинный start — да. Не смешивать с фактом паспорта без калибровки.

### I4–I9. Последовательность на выходе

Не одна картинка — несколько представлений **одной** хронологии. MVP: лента шагов + полярная ромашка + метраж.

### I10–I15. Нить как объект правки (после сшитого мари)

Якорь — **физическая** нить (`WorkingThread`), не «цвет на экране».

- Подсветка до обреза.
- Перекрас — свободно.
- Замена материала / удаление — сценарий «распустить: B3, A3, B2…», чтобы было ясно, сколько слоёв жалко на живом мари.

### I16. Рамка «зачем это мастеру»

Разметка, порядок стежков, разбор брака, «а что если», язык с ученицей. Не замена натяжению и ушку иглы.

### I17–I18. Навигация и ученица (к схемам I4–I9)

Лента и 3D — один текущий шаг. Призрак следующего catch учит укладке до прокола, не «шьёт за тебя».

### I19–I20. Роспуск осмысленнее (к I14)

Сначала превью цены (слои + мм), плюс «кто лежит сверху» — иначе список роспуска слепой.

### I21. Равные круги к экватору

Счётчик оставшихся пар A/B, чтобы не уехать одним цветом дальше другого.

### I22–I23. Унести со стола / показать одной нитью

Печатный дневник и шаринг с уже включённой подсветкой `WorkingThread`.

### I24–I25. Перед стартом и после факта

Чеклист булавок; позже — факт длины в паспорт рядом с моделью (не путать с автозакупкой).

## Одна фраза (когда понесёшь инженеру *эти* идеи)

> Метраж всех зон по нити/цвету + прозрачный мари для проверки; выход — лента шагов и полярный обзор; тап = вся непрерывная нить до обреза; перекрас свободно; замена/удаление через явный список «распустить N слоёв».  
> Рядом (тот же пакет идей): синхрон «где я», призрак следующего стежка, превью роспуска и генеалогия нити, счётчик до экватора, дневник/ссылка на одну нить, чеклист булавок, калибровка факт↔модель в паспорт.
