# Темари — правила, к чему чинить

Источник традиции: TemariKai (wrapping the mari, standard divisions, glossary).
Это не бэклог фич. Это инварианты. Баг = нарушили строку отсюда.

**Как выглядит — тоже правило.** Зелёный тест не заменяет кадр. Смотреть не только «готово»: чуть намотал — посмотрел. Сверять три вещи: что говорит код, что на кадре, как мотает мастер (TemariKai, не «похоже на нитку»). Порядок и кадры — §9.

**Идеальный мастер.** Игрок не может намотать криво. Жест — скорость и направление следующего круга, не физика нити. Спираль, излом, горб на полюсах, плоскость мимо центра, «почти октаэдр» C8 — недостижимы, не штрафы. Геометрия всегда точная, чтобы потом считать метраж нити для реальной покупки.

Порядок работы всегда такой. Нельзя переставлять.

```
син (ядро) → маки (база) → дзивари (разметка) → кагари (вышивка)
```

Спираль (узумаки) — стежок или декоративный приём, **не** способ мотать базу.

Ядро S² — направление, не перепись. GreatCircle, покрытие на сфере, метраж, property tests — после честной Simple+кику. Не `geometry/vec3.ts`, не event sourcing, не резать store, пока шар лысый. Веха: «ядро · S²».

## 0. Инварианты сферы

1. Нить базы и линия дзивари всегда идут **по большой окружности** (полный обхват). Иначе нить сползает.
2. Две подряд идущие намотки **не** лежат рядом и **не** совпадают. Шар в руках всё время чуть поворачивается.
3. Поверхность после базы — как войлок: нет основы/утка, нет решётки из семейств окружностей.
4. Шар остаётся **круглым**. Утолщение на полюсах недостижимо: мастер так не мотает.
5. Стежок лежит **на** мари, не хордой в воздухе.
6. Разметка поверх намотки, не внутри и не под ней.
7. Булавка — метка. Нить её **обходит** (и копится слоем), а не пришивается к ней.

## 1. Син — ядро

В игре ядро можно не симулировать. В реальности:

- Сначала мягкий ком (ткань / бумага / пенопласт).
- Потом слои: толстая пряжа → тоньше → швейная нить.
- Размер задаёт ядро, а не бесконечная намотка.
- Неровное ядро = кривая разметка = кривой узор.

Игра: шар уже круглый и закрыт толстой пряжей (шерсть на ядре). Игрок мотает **только последний слой** — тонкую швейную нить. Три материала руками не гоняем.

## 2. Маки — намотка базы

Цель: закрыть ядро ровным случайным слоем нити, чтобы получился dodai mari.
С этого всегда начинают. Пока база не закрыта — нет булавок, нет дзивари, нет кагари.

### Как мотают в руках (TemariKai + лайфхаки)

- Нить всегда идёт на **полный обхват** — самая большая окружность. Иначе сползает.
- Шар в руках **всё время чуть поворачивают**. Два круга подряд не лежат рядом и не совпадают.
- Направление корда одно: нить с катушки только сматывается на шар. Назад по тому же следу не едут — размотается или ляжет жгутом.
- Если рука пошла «не туда», шар **подворачивают** под нить: плоскость обхвата чуть меняется, нить всё равно ложится вперёд.
- После круга ось сдвигают примерно на **толщину нити**, чтобы следующий обхват не прошёл через те же полюса. Иначе на полюсах горб.
- Плоскость ещё и хаотично меняют — как в руках, без сетки меридианов. Поверхность в конце как войлок: нет основы/утка.
- Натяжение ровное: держит, но не свистит и не плющит шар.
- Слои: толще → тоньше. В игре один рабочий слой нити на уже круглом ядре.
- Два цвета подряд — это уже узор (maki kagari / оби), не база.

### Чего нет в базе

- Спирали (узумаки). Нить сползет с широты.
- Свободного вращения «куда ткнул» без экватора обхвата.
- Булавок. Нечего метить.
- Сетки, клеток, видимых семейств больших кругов.
- Размотки жестом назад.

### Контракт игры — нельзя намотать неправильно

Игрок не симулирует руки новичка. Он задаёт темп и, после круга, куда чуть повернуть узор базы. Всё остальное — идеальный мастер маки.

1. Первый жест задаёт сторону намотки.
2. Любой жест **только добавляет** нить. Назад не сматывается.
3. Жест против стороны — шар **подворачивается** (сдвиг плоскости на ~толщину нити) и снова мотает вперёд.
4. Нить всегда на текущем экваторе большого круга.
5. После полного круга полюса **сдвигаются** на толщину нити плюс небольшая прецессия — не меридианы в одну точку.
6. Двумя пальцами можно чуть сменить плоскость (как в руках выбрать, куда пойдёт следующий обхват) — это и есть «хаос узора» базы. Всё равно большой круг.
7. Слой готов, когда семпл покрытия закрыл ядро, а не когда натикали N кругов.
8. Скорость жеста = скорость намотки. На форму витка не влияет.

### Когда база готова

- Ядро не просвечивает.
- Поверхность ровная, без горба на полюсах.
- Нет выделенных меридианов и экватора — их ещё не клали.

### Слои рельефа

Нить имеет толщину. Где круги пересеклись — чуть выше. Где шла рядом — гребень. Это не клетка из 4 осей, а слабый случайный рельеф. Когда нить обогнёт булавку (уже в дзивари/кагари) — локально ещё выше.

### Что в игре сейчас

| Правило | Сейчас |
|---|---|
| Большой круг | да, `MariWinder` |
| Не спираль | да, спираль выпилена |
| Прецессия после круга | да, `nextWrap` |
| Булавок в базе нет | да |
| Вращение только в плоскости обхвата | да, плюс подворот при жесте назад |
| Одна сторона, без размотки | да, `commitSpin` / `tuck` |
| Полюса сдвигаются на толщину нити | да, `nextWrap` miss = tilt |
| Реальные витки, а не шейдер | в работе: холст обхватов поверх ядра, войлок только в дырах |
| «Готово» при дырах | покрытие — равномерные точки на сфере, не UV-вес |
| Дыры можно замотать руками | нет: покрытие считается семплом, «залить» закрывает всё |
| Толщина нити влияет на шаг | да, `threadWidth` → tilt / freq |

Фикс базы = эти строки, не «красивее шум».

## 3. Дзивари — разметка

Дзивари — нити-территории на готовой мари. Это **не** вышивка.

### Две разные вещи

- **Линия деления** — полный обхват, режет шар на две полусферы. Все линии деления — разметочные.
- **Разметочная линия** — может быть отрезком, не обязательно полный круг.

Нить разметки тонкая, контрастная к базе, лежит сверху.

### Как ставят

Два инструмента. Не линейка по столу.

1. **Полоска** — обхват C. Simple: сложил → NP, SP, экватор, шаг C/N.
2. **Угловая линейка (V)** — C10. Угол 72°. Дуга между центрами `C/6 + C/100`. Из бумаги или пластик JTA. Нечётные доли — шаблон 360°/n.
3. Булавки-метки — полюса и точки с полоски / с V.
4. Нить якорится и идёт **с одной стороны булавок** (выбрал сторону — держись).
5. У полюса **частичный поворот вокруг булавки** — переход на следующую долю. Это не смена направления базы руками.
6. Пересечения **прихватывают** крошечным стежком (tack). Булавку не вынимают, пока точка не прихвачена.
7. Keeper pins — временные, держат пучок, пока не закрепили. Не путать с метками углов фигуры.

### Стандартные деления

На сфере равномерно расставить полюса можно не как угодно. Стандарт:

**Простое / Simple N** (у нас «Простое» ≈ S8)

- Север и юг.
- Экватор всегда, если узор не сказал иначе.
- N меридианов: NP → экватор → SP → противоположный экватор → NP.
- Полюс — N-луч. Доли как дольки апельсина.
- S4, S6, S8, S10, S12, S16 — одно семейство, разное N.
- Простое 16 часто для кику.

**C8** (8 等分の組み合わせ)

- Начинается как Simple 8.
- Добавляют ещё 8-лучевые центры, пока все 6 полюсов не встанут равномерно (октаэдр).
- Итог: 6 восьмилучевых (квадраты), 8 шестилучевых (треугольники), 12 четырёхлучевых (ромбы).

**C10** (10 等分の組み合わせ)

- Начинается как Simple 10.
- 12 десятилучевых полюсов (икосаэдр / пентагоны).
- Итог: 12 пятиугольников, 20 треугольников, 30 ромбов.
- Шаг между центрами — V-линейка: `C/6 + C/100` (C — обхват).
- Постоянных «севера и юга» нет: симметрия 3D. Временный полюс только чтобы начать.

Другие разметки (S6, tamentai, extra mentai) — после того, как эти три не врут.

### Чего дзивари не делает

- Не закрывает базу.
- Не прячется под войлок.
- Не рисуется толстыми трубками-клетками.
- Не ставится, пока база дырявая.

### Что в игре сейчас

Шейдер граней — это не дзивари. В студии после базы кладутся тонкие нити по большим кругам Simple / C8 / C10 и булавки на полюсах, поверх намотки.

## 4. Кагари — вышивка

Кагари буквально «как подрубочный стежок». Нить ходит по уже лежащим линиям дзивари.
Игрок либо ведёт стежок за стежком в правильном порядке, либо просит заполнение.
Как заполняется (шаг, нахлёст, метраж) — наша физика, не жест.

### Общие правила стежка

- Игла входит/выходит у разметочной нити, обычно **обхватывая** её.
- Ряд идёт вокруг фигуры (полюс, многоугольник, пояс).
- Следующий ряд ложится **к** предыдущему: либо наружу (лепесток растёт), либо внутрь (фигура густеет).
- Нельзя прыгать через сектор «потому что ближе». Порядок обхода задаёт узор.
- Нить того же калибра, что вышивка, не толще разметки в 5 раз.
- Слои: новый ряд чуть выше старого. У булавки / полюса нитки складываются.

### Направление

- **Наружу / uwagake-chidori от центра:** рабочая нить переходит *поверх* уже сшитого, лепесток растёт от полюса.
- **Внутрь / sakasa:** тот же стежок, но с внешнего края к центру.
- В игре это `KagariDir`: `out` | `in`.

### Узоры, которые мы назвали

**Кику** — хризантема. Много лепестков от полюса. Классика: ёлочка (chidori) вдоль лучей простого деления. Ноги лепестка идут по соседним меридианам, сходятся у полюса, ряд за рядом расширяются. Не «клетка на шаре» и не лента, висящая над полюсом.

**Хоси** — звезда. На 5 лучах обход через один: `a-c-e-b-d-a`. Нужен 5- или 10-лучевой центр (C10 / S10).

**Хиси** — ромб. Один круг стежка даёт алмаз на 4-лучевом центре (их много на C8/C10).

**Оби** — пояс по экватору. Может быть сшит или намотан (maki obi). Это узор, не база. Малая окружность параллельно экватору — здесь законно, потому что её держат дзивари и/или keeper pins.

### Пример-рецепт (TemariKai, 8-point kiku)

Не S4 и не C10. Один шар:

1. Маки закрыла ядро.
2. Полоска → Simple 8 (NP, SP, экватор, 8 лучей), нить с одной стороны, прихват.
3. Булавки стежка: верх у полюса; низ — **вверх от экватора** (⅓ или ½ дуги), не вниз от полюса.
4. Кику на севере: зигзаг по соседним лучам, ряд = два прохода (нечёт / чёт). Следующий ряд к предыдущему; нижний угол сдвинуть на толщину нити.
5. То же на юге.
6. Maki obi по экватору; на пересечении с меридианом — крестик.

Дыры дока, не «потом»: низ от экватора, два прохода, растяжка угла, крестик оби. Увагакэ vs ёлочка — #53.

**Ряд** — свободный стежок по сетке, без мотива. Учебный режим.

**Maki kagari** (обёрнутые пояса) — декоративная намотка поверх разметки, полный обхват, можно через keeper pins. Не путать с маки базы.

**Узумаки** — спиральный стежок/мотив. Не режим базы.

### Что в игре сейчас

Кику-пресет рисует ленту у полюса. Это картинка, не стежки вокруг дзивари. Хоси/хиси/оби — подписи, не те же правила.

## 5. Булавки

| Тип | Зачем | Когда |
|---|---|---|
| Marking | полюс, экватор, угол фигуры | дзивари и кагари |
| Keeper | удержать пучок, пока не прихватили | оби, maki kagari, набор у полюса |
| Рабочая в кагари | якорь угла, нить её обматывает | пока шьём |

Правила:

- В базе булавок нет.
- Смена направления базы ≠ оборот вокруг булавки.
- Нить проходит **с одной стороны**, если булавка не стоит криво.
- Снять булавку можно только после прихвата.
- Вокруг булавки нить реально наматывается — локальный холмик.

## 6. Геометрия, которую нельзя «нарисовать примерно»

- Большой круг: центр шара в плоскости нити.
- Simple N: поворот вокруг оси полюсов на `π/N`.
- C8: 6 полюсов как вершины октаэдра.
- C10: 12 полюсов как вершины икосаэдра; соседние на V-расстоянии.
- Стежок кику: короткая дуга **по сфере** между двумя соседними лучами, на фиксированной колошироте, затем колоширота += шаг нити.

Если визуально красиво, но это не выполняется — это баг, не стиль.
Игроку эти состояния недоступны: система так не кладёт.

## 7. Режимы игры ↔ фазы

| Режим | Фаза | Что можно |
|---|---|---|
| Title | витрина | готовая мари + кику, без работы |
| Studio / Намотка | маки | только большой круг, толщина, цвет базы, «готово» |
| Studio / Метки | дзивари | булавки + тонкие полные круги, прихват |
| Studio / Кагари | кагари | стежки по разметке, мотив, направление |
| Kata | то же по шагам | пазл проверяет деление/заливку граней — это упрощение, не дзивари |

Нельзя шить, пока база не закрыта.
Нельзя мотать базу, уже перейдя в метки (слой зафиксирован).

## 8. К чему фиксить, по приоритету

1. **Маки выглядит как слой ниток, а не как клетка и не как пластик.** Рельеф от реальных кругов / честной симуляции обхватов, без 4-осевой решётки.
2. **Дзивари — видимые тонкие нити поверх базы**, по правилам Simple / C8 / C10, с булавка→поворот→прихват.
3. **Кику шьётся по этим нитям**, ряд за рядом, на сфере, слоями.
4. **Нить вокруг булавки** даёт холмик.
5. Хоси / хиси / оби — только когда 1–4 не врут. Иначе выключить.
6. Ката перевести с «залей регион» на «разметь и вышей».

Шейдер войлока — заглушка пункта 1, не конечная форма.

## 9. Как смотреть

Картинка обязательна. Инварианты ловят геометрию; шапочки, двойной штрих, разводы — нет. Их видно только на кадре.

Не ждать полного слоя. Смотреть по ходу:

| Кадр | Что должно быть | Чего нет |
|---|---|---|
| 0 витков | шерсть ядра, один материал | светлые шапочки, меридианы, сетка |
| 1 обхват | один большой круг, замкнут, одна толщина | разрыв, двойная нить, эллипс у полюса |
| середина витка | плоскость та же | сдвиг оси, излом |
| несколько кругов | пересечения как войлок | семейство параллельных, основа/уток |
| слой закрыт | ядро не просвечивает, нет долей | «готово» при дырах |
| дзивари поверх | тонкие метки сверху базы | метки внутри слоя, толстые несущие |

Агент (и человек) после правки маки:

1. Открыть студию намотки, не только титул.
2. Снять кадры: 0 / один круг / несколько / «готово». Не один финальный PNG.
3. Смотреть шар, не консоль. DevTools / Playwright / превью — всё равно: **смотри на пиксели**.
4. Спросить вслух: «код думает, что это один большой круг. На кадре это один большой круг?» Если нет — баг, даже если `n·x=0`.
5. Сверить с фактом ремесла, не с прошлым скрином игры. Источник: TemariKai, wrapping the mari. Войлок без основы и утка. Не спираль. Не меридианы через одни полюса.

Нельзя считать правку намотки сделанной без кадра «один обхват». Нельзя чинить «на глаз по коду».

Оракулы холста (#74) — страховка к этим кадрам, не вместо них. Golden всего экрана не кладём: устареет и останется зелёным.

### Кто закрывает

Кайф игры — как движется, слышится, видится. Это не закрывает агент.

- Метка **кайф**: баг про вид / жест / звук. Агент не ставит `state: closed`.
- Метка **смотри**: агент считает, что сделал. Передаёт человеку. Issue остаётся открытым.
- Закрывает **только человек**, после кадра (и жеста, и звука, если это про них).
- Не ок: снять «смотри», написать что видно. Агент чинит дальше.

`ждёт решения` — другое: выбор, не проверка глаз.

Агент после правки кайфа: лейбл «смотри», комментарий что смотреть, push. Не close.
