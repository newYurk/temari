# Локальный паспорт работы

Первый технический срез [#95](https://github.com/newYurk/temari/issues/95), 19.09.2026, ветка `codex/temari-next`. Продуктовое направление: [программа мастеров](../docs/craft-calibration-program.md). Сервер, аккаунты, сбор email, калибровка и платежи не включены.

## Сценарий

Открыть `passport.html` с титульного экрана игры либо из `s8-ab.html`. Переход из образца подставляет только параметры полного A1/B1 одного полюса, не текущее положение пошагового ползунка. Это инженерный пример, не измеренная работа пользователя.

Параметры → зафиксировать прогноз или его отсутствие → добавить отдельные факты → сохранить полный JSON. Для продолжения открыть сохранённый JSON через «Открыть JSON». Новая работа и замена непустого паспорта требуют подтверждения; неудачный импорт оставляет прежнюю работу.

## Сохранение и приватность

- **Вкладка:** React state. Нет `localStorage`, `sessionStorage`, IndexedDB, cookies, сервера или автосохранения. Уведомление об этом постоянно видно; невыгруженные изменения вызывают стандартное предупреждение при уходе, когда браузер его разрешает.
- **Полный паспорт:** `temari-passport.json`, формат `temari-local-passport`, `schemaVersion: 1`. Содержит название/заметки/описания нитей, даты, локальные ID, параметры и историю. Это личный рабочий файл, не анонимный экспорт.
- **Экспорт сравнения:** `temari-comparison.json`, формат `temari-comparison-export`. Строится по белому списку: структурированные параметры, категории материалов, цвета, исходные числа/единицы, версии модели и факты. Исключены все свободные строки, даты и локальные ID; ссылки между фактами и прогнозами заменены индексами внутри файла. Контактных полей нет.
- **Свободные марки/артикулы:** сохраняются только в полном паспорте. В обезличенном наборе остаётся признак `freeTextMaterialDetailsOmitted`; точного справочника брендов пока нет. Этот экспорт не является законченным материал-специфичным датасетом калибровки.
- **Передача:** скачивание выполняется только кнопкой. Приложение ничего не отправляет; единственный запрос данных страницы — чтение статического описания модели.

Экспорт сравнения намеренно не открывается как полный паспорт: в нём нет исключённых полей и полной истории происхождения. Удаление cookies не уничтожает уже скачанный файл, но закрытие несохранённой вкладки может потерять текущие изменения. Интерфейс не обещает, что нажатие на скачивание гарантирует сохранение файла: просит проверить загрузки.

## Что входит в паспорт

Исходный размер готовой основы, окружность либо диаметр, мм либо см; точный ID разметки; известный S8-рецепт либо явно «другой»; область работы, центры и ряды. Для двух групп A/B: категория нити, диаметр, число сложений, цвет и локальное описание марки/серии/артикула. Другие рецепты можно документировать, но они не становятся реализованными от наличия строки в паспорте.

Новый паспорт не придумывает размер шара. Пустое числовое поле — `null`, а не ноль. Десятичные точка и запятая допустимы. Диаметр не выдаётся за измеренную окружность: исходное значение сохранено, производная величина помечена как вычисленная.

## Прогноз

`scripts/build-passport-model.mts` извлекает длины из `public/fixtures/s8-ab.json`, проверяет свежесть исходников и заново проверяет обе отображаемые кривые. Маленький `public/fixtures/passport-model.json` хранит SHA-256 исходного снимка/модели, размер и длины A/B с разбиением surface/piercing/buried.

Поддержан только инженерный C230, S8, один полюс, первый проход A1/B1, две нити по 0,4 мм в одно сложение. Нет масштабирования на другой размер/толщину, умножения на дополнительные ряды/полюса и закупочных коэффициентов. Категория реального материала сама по себе не калибрует его механические свойства; каждый доступный прогноз явно `calibrated: false`.

Каждый прогноз сохраняет копию параметров и всей версии расчёта. Изменения текущей формы или новой версии модели не переписывают старую запись. Недоступный прогноз хранит причину и `model: null`, не нулевые метры. Импорт старой версии сохраняет её числа с предупреждением, что текущая страница не может сверить их по прежнему источнику; числа известной текущей версии сверяются со статическим описанием.

Точность сравнения параметров при пересчёте диаметра/окружности учитывает только округление floating-point. Это не допуск на подмену физического размера и не эмпирическая калибровка.

## Факт и сравнение

Факт хранит свою копию параметров, область, компонент, A/B/обе нити, исходное число/единицу и необязательную погрешность. Метод: измерение до/после, отрезки минус остатки либо приблизительная оценка. Записи добавляются отдельно; этот срез не включает редактор/удаление исторических фактов или автоматическое объединение повторных наблюдений.

- Области либо параметры различаются: численная ошибка не вычисляется.
- Намотка/разметка/концы/отходы: отдельные компоненты, не сравниваются с общей длиной вышивки.
- Купленное количество: сохраняется, но не считается расходом.
- Общий расход с катушки: показывается превышение над геометрией с предупреждением о концах/отходах, не «чистая ошибка модели».
- Приблизительная оценка: явно не точное измерение.
- Совпадающая область и измеренная длина в изделии: вычисляется разница и отношение к прогнозу; это не принятие модели по реальным материалам.
- Незаписанное число в форме факта блокирует выгрузку, пока пользователь не добавит факт либо не очистит ввод.

## Контракты файлов и ошибки

До 1 МБ, не больше 100 прогнозов и 500 фактов. Неизвестная версия, лишние поля, дубли ID, ссылки на отсутствующий прогноз, нечисловые/отрицательные значения, недопустимые единицы, противоречивая сумма частей пути или изменённые числа известной модели отвергаются. Парсер не дописывает неизвестные поля в экспорт и не исполняет содержимое строк.

При недоступной модели можно сохранить паспорт и факт без прогноза. Текущее игровое сохранение `temari-v1` не читается и не перезаписывается этим инструментом.

## Проверки и команды

```sh
npx tsx scripts/build-passport-model.mts --write
npx tsx scripts/build-passport-model.mts --check
npx tsx --test src/components/temari/craft-passport.test.ts
npm run typecheck
npm run build
```

Сборка и CI требуют актуальный источник прогноза. Юнит-проверки покрывают неизменяемость, единицы, несовпадения, пропуски/нули, импорт и приватность экспорта. Браузерная проверка включает download → reload → upload, подменённые/будущие файлы, отмену замены, ошибки модели, работу при заблокированных хранилищах, светлую/тёмную темы и ширины 1280/390/320. Физический решатель в этом срезе не изменён и заново не запускался.

Итог 19.09: 120 целевых тестов прошли, из них 30 новых для паспорта; typecheck/build, свежесть трёх генераторов, зеркала и vault проверены. Отдельно проверены 200% размер текста, видимость погрешности, файл >1 МБ и прямые ссылки из игры/документа/контрольного образца.
