# санкаку

三角かがり（sankaku kagari） · triangle stitching

треугольник за круг по трём сторонам грани.

- Семья: polygon
- Механика: Механика · укладка стежка
- Состояние: **к первой версии**

## Каким узорам нужен

- хиси

## Достижимость в игре

- В интерфейсе: только данные, кнопки нет
- Движок называет этот стежок: **нет** — рецепт его не знает
- Узоров, которые им действительно шьются: 0 из 1
