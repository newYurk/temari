# Отклонённые переходы третьего подхвата

Эти файлы — воспроизводимые отрицательные эксперименты, **не реализация мастерской**.
Оба patch применяются независимо к `fe572dd`; один поверх другого применять нельзя.
Не применять их в рабочей ветке ради красивого кадра: каждый нарушает геометрию толстой нити.
[Разбор](../../2026-09-23-catch-geometry-boundaries.md).

- `baseline-section.json` — две строгие общие точки поверхностей на исходном меше,
  полный состав проверяемых пар, вершины и барицентрические координаты, digest исходников.
- `rejected-wide-approach.patch` — переход от границы 6 мм к фиксированному порту:
  точные порты, но увеличение коллизий и недопустимая кривизна.
- `rejected-short-approach.patch` — сохраняет фланг до последней поддержанной наружной
  точки. Пересечений меньше, но кривизна всё ещё недопустима внутри перехода.
- `measure-rejected-curvature.mts` — аналитические производные использованного
  радиально-нормализованного cubic; 1001 проба на каждый подход. Запускать только
  в отдельной копии исходного кода с соответствующим patch.
- `rejected-short-curvature.json` — результат короткого варианта; 16 из 32 подходов
  нарушают необходимое условие `минимальная полуось × кривизна < 1`.

Для воспроизведения: отдельная копия `fe572dd`, её зависимости; применить **один** patch,
скопировать туда данный скрипт с тем же относительным путём и запустить
`node --import tsx reviews/experiments/2026-09-23-catch/measure-rejected-curvature.mts`.
Нарушение в точке достаточно для отказа; прохождение сетки не доказывает всю кривую.
На действующем коде без patch скрипт явно отказывается работать.

Идентичность проверенного короткого кандидата (SHA256):

```text
src/components/temari/stitches.ts
29111b25d28cc1a8901187884569fd85adbcdee954877d03fc2b62ce6580f90f
src/components/temari/fixed-port-approach.ts
2fcf4584cde7db6172d324c847f56b20e7f554fae686fe6077f5cb61f32fae0d
```

Актуальная независимая проверка третьего подхвата находится вне экспериментов:
`npm run check:upper-section` (также `-- --both-sets`). Она должна продолжать
сообщать об отказе, пока не устранено пересечение реальных поверхностей.
