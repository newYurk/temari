# «Тэмари дня» — прототип

Отдельная страница вне приложения, 23.09.2026. Каждый день даёт новую раскладку кику на S8:
гамма (намотка и нити), число кругов от 6 до 10, цвета по кругам. Шар шьётся на экране по рядам
в порядке мастера (север A1, B1, A2…, затем юг), кладётся на полку, для него есть рецепт.
Вторая вкладка — «Куда расти»: идеи, как улучшить Темари, спокойные игровые механики и заработок.

**Статус:** прототип для обсуждения с владелицей. В приложение не подключён, `src/`, тесты и
сборку сайта не меняет. Ремесленной приёмки нет.

## Откуда геометрия

Не рисунок: осевые линии нитей берутся из модели мастерской. `pileParts` — стопка по порядку
шитья, `motifStitchPlan` — рецепт кику GT14 на S8. Выгружаются оба полюса по 10 кругов;
у каждого круга свой цвет, то есть это отдельная нить. Скрипт проверяет, что первые N кругов
совпадают с началом выгрузки на 10 кругов, а юг не зависит от севера (расхождение 0).
Прореживание Douglas–Peucker — 0,03 мм. Метраж считается по пути нити в модели: по
поверхности и в проколах, для мари 24 см. Хвосты и запас на иглу не входят, числа не
откалиброваны. Известные ограничения модели (лесенка у верхних остриёв) видны и здесь.

## Как собрать

Из корня репозитория, Node 24:

    node --import tsx prototypes/temari-day/tools/dump-kiku.mts   # data/: геометрия и проверки (stats.json)
    node prototypes/temari-day/tools/build-page.mjs                # out/temari-day.html — одна страница
    node prototypes/temari-day/tools/check-page.mjs                # проверка в безголовом Chrome

`out/temari-day.html` — самодостаточная страница, около 270 КБ. three.js 0.185.1 подгружается
с jsdelivr; если не загрузился, показывается плоская «ромашка». Страница рассчитана на
публикацию как Artifact claude.ai: там печать недоступна, поэтому рецепт и полоски разметки
скачиваются SVG-файлом A4 в миллиметрах. При печати в масштабе 100 % контрольная линейка
должна быть ровно 50 мм. `data/`, `out/` и `shots/` не коммитятся.

## Что внутри страницы

- **Шар дня.** Зерно — локальная дата: cyrb53 → mulberry32. Гамма не повторяется внутри
  14 дней. Раскладки: «две нити, как в GT14», полосы, перелив от центра, шахматка A/B.
- **Шитьё.** Ряды появляются в настоящем порядке, у каждого ряда тихий звук — тоны из `feel.ts`.
- **Полка** — в `localStorage` этого браузера.
- **Рецепт.** Две «ромашки» (азимутальная проекция, вдоль лучей 1:1 для мари 24 см), таблица
  кругов, метраж по цветам, бумажные полоски меридиана и экватора под введённый обхват.
